## Descripcion

Analisis de vecindad y autocorrelacion espacial del porcentaje de
poblacion que completo la educacion secundaria en los distritos
de los tres departamentos asignados.

Se utilizan cuatro criterios de vecindad:

- Rook
- Queen
- K vecinos mas cercanos (KNN)
- Banda de distancia

Se calcula el indice I de Moran global y local para obtener
cuatro mapas LISA, identificando agrupamientos espaciales
y valores atipicos.
